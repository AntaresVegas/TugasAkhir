\section{Latar Belakang}
\label{sec:1:latar_belakang}

   Perkembangan teknologi web yang sangat pesat menyebabkan halaman web modern memiliki struktur yang semakin kompleks. Setiap halaman web dibangun menggunakan \textit{Hypertext Markup Language} (HTML) yang secara umum dapat direpresentasikan dalam bentuk struktur hierarkis yang dikenal sebagai \textit{Document Object Model} (DOM). Struktur DOM ini berbentuk pohon (\textit{tree}) yang terdiri dari elemen-elemen HTML yang saling terhubung melalui hubungan induk (\textit{parent}) dan anak (\textit{child})~\cite{marini:02:thedom}.

    Meskipun struktur DOM merupakan konsep dasar dalam pengembangan web, representasinya dalam bentuk kode HTML sering kali sulit dipahami secara langsung, terutama pada halaman web yang memiliki banyak elemen. Oleh karena itu, diperlukan suatu cara yang dapat membantu menyajikan struktur tersebut dalam bentuk yang lebih mudah dipahami.
    
    Salah satu cara yang dapat digunakan adalah dengan memvisualisasikan struktur halaman web dalam bentuk graf. Dalam pendekatan ini, setiap elemen HTML pada satu halaman web direpresentasikan sebagai simpul (\textit{node}) dan hubungan antar elemen direpresentasikan sebagai sisi (\textit{edge}). Graf yang dimaksud pada penelitian ini adalah graf struktur DOM dari satu halaman web, bukan graf tautan antar halaman pada suatu situs. Dengan demikian, struktur DOM dapat dilihat secara lebih jelas dan terstruktur.
    
    Berdasarkan permasalahan tersebut, tugas akhir ini berfokus pada pengembangan perangkat lunak yang mampu mengambil dokumen HTML dari suatu \textit{Uniform Resource Locator} (URL), membangun struktur DOM, dan merepresentasikan struktur DOM dari halaman tersebut dalam bentuk graf yang dapat divisualisasikan. Perangkat lunak ini diharapkan dapat membantu pengguna dalam memahami struktur halaman web secara lebih mudah.

\section{Rumusan Masalah}
\label{sec:1:rumusan}

Rumusan masalah yang akan dibahas pada tugas akhir ini adalah:
\begin{enumerate}
    \item Bagaimana cara mengambil dokumen HTML dari suatu situs web berdasarkan URL serta membangun struktur DOM?
        
    \item Bagaimana cara merepresentasikan struktur DOM ke dalam bentuk graf yang terdiri dari (\textit{node}) dan (\textit{edge}) melalui proses traversal yang sistematis?
        
    \item Bagaimana merancang perangkat lunak yang mampu menghasilkan visualisasi graf dari struktur DOM satu halaman web secara otomatis dan mudah dipahami pengguna?
\end{enumerate}

\section{Tujuan}
\label{sec:1:tujuan}

Tujuan yang ingin dicapai skripsi ini adalah sebagai berikut:
\begin{enumerate}
    \item Mengambil dokumen HTML dari suatu situs web berdasarkan URL serta membangun struktur DOM.
    
    \item Merepresentasikan struktur DOM ke dalam bentuk graf yang terdiri dari (\textit{node}) dan (\textit{edge}) melalui proses traversal yang sistematis.
    
    \item Merancang perangkat lunak yang mampu menghasilkan visualisasi graf dari struktur DOM satu halaman web secara otomatis dan mudah dipahami pengguna.
\end{enumerate}

\section{Batasan Masalah}
\label{sec:1:batasan}

Pengerjaan tugas akhir ini memiliki batasan sebagai berikut:
\begin{itemize}
    \item Perangkat lunak dikembangkan menggunakan bahasa pemrograman Java.
    \item Sistem memproses satu halaman web berdasarkan URL yang dimasukkan oleh pengguna dan tidak melakukan \textit{web crawling} ke halaman lain.
    \item Sistem menganalisis dokumen HTML yang diperoleh dari URL dan tidak mengeksekusi JavaScript sisi klien.
    \item Elemen yang dipetakan ke dalam graf adalah elemen HTML pada struktur DOM, sedangkan teks, atribut, dan komentar tidak dijadikan \textit{node} utama.
    \item Hasil visualisasi graf dibuat menggunakan format DOT dan Graphviz.
    \item Halaman web yang diproses adalah halaman yang dapat diakses secara publik tanpa autentikasi khusus.
\end{itemize}

\section{Metodologi}
\label{sec:1:metlit}

Metodologi pengerjaan tugas akhir ini adalah sebagai berikut:
\begin{enumerate}
    \item Melakukan studi literatur mengenai HTML, DOM, struktur data graf, Graphviz, dan metode traversal.
    \item Melakukan analisis kebutuhan serta perancangan arsitektur perangkat lunak yang akan dikembangkan.
    \item Mengimplementasikan sistem untuk mengambil dokumen HTML, membangun struktur DOM, serta merepresentasikannya dalam bentuk graf.
    \item Melakukan pengujian menggunakan beberapa halaman web dengan struktur yang berbeda serta mengevaluasi kesesuaian daftar \textit{node}, daftar \textit{edge}, dan hasil visualisasi graf.
    \item Melakukan analisis terhadap hasil visualisasi berdasarkan keterbacaan graf, kesesuaian relasi \textit{parent-child}, dan keberhasilan pembentukan berkas DOT.
    \item Menyusun dokumentasi dan laporan tugas akhir.
\end{enumerate}
